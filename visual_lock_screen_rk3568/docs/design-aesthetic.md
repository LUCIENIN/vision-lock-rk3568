# 视觉识别锁屏美学规范（v0.3）

本次设计采用清晰层次的中文信息布局，并以夜间护眼渐变为主：
- 主色：`#0ea5e9`（高亮）+ 深蓝灰底 (`#0b1220` → `#0f172a`)
- 字重：中文标题用粗体中文无衬线，说明文字用中等字重
- 节奏：每次触发固定展示 3~12 秒，默认 12 秒自动消失
- 视觉层：
  - 上层：标题/副标题，突出 “已检测到人形”
  - 中层：时间、设备状态、提示短句
  - 底层：留白和弱色说明，避免干扰主视觉
- 交互：
  - 锁屏可被用户按 `Esc` 关闭（overlay 模式）
  - i3lock 后端通过 `i3lock -n -i <image>` 显示离线背景，不依赖外部动态库

与文档映射：
- 对应 PRD `PRD_visual_lock_screen_v0.2.md` 的“中文展示与触发反馈”
- 对应技术方案 `Tech_implementation_plan_visual_lock_screen_v1.md` 的“低功耗持续识别/异常降级思路”
